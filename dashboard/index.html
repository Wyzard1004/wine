RESEARCH QUESTION

How does k-NN accuracy change when principal components replace original features?

We compare k-nearest neighbours using all 13 standardised chemical features against the same classifier using 2, 5, or 10 principal components. This directly follows the project proposal.

Preprocessing stays inside the fold

A scikit-learn pipeline fits the scaler and PCA only on each training fold. The held-out samples use those fitted transformations. The baseline omits PCA and otherwise uses identical settings and splits.

The reference result is fixed in advance

The main comparison fixes k = 5. The neighbour selector on the overview explores sensitivity; it does not tune a model or alter the reference table. Confusion matrices always use the reference experiment.

Tuning gets its own evaluation

A separate nested cross-validation extension chooses k inside each outer training fold, then evaluates it on the untouched outer fold. Its results below are distinct from the exploratory sensitivity sweep.

Interpretation has limits.

Fold scores share overlapping training data and are not independent replications. A higher cross-validation mean on this small dataset does not establish superiority, causality, or performance on wines from other populations.
